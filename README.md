# Selenium Java Hybrid Automation Framework

This project is a Hybrid Test Automation Framework developed using Selenium WebDriver, Java, TestNG, Maven, Rest Assured, and Extent Reports. The framework is designed to support both UI and API automation testing while following industry-standard design principles such as Page Object Model (POM), reusable utilities, centralized configuration management, and detailed reporting.

## Key Features

* Selenium WebDriver for UI Automation
* TestNG Test Execution and Assertions
* Maven Build Management
* Rest Assured API Testing
* Extent Reports with Screenshot Integration
* Configurable Test Execution using Properties Files
* Page Object Model (POM) Design Pattern
* Reusable Utility Methods
* Screenshot Capture on Failure
* Browser Factory / Driver Management
* Maven Command Line Execution
* Scalable and Maintainable Framework Structure

## Technologies Used

* Java
* Selenium WebDriver
* TestNG
* Maven
* Rest Assured
* Extent Reports
* Git & GitHub
* Appium

## Execution

Run the complete suite using:

mvn clean test
